2.13. Знайдіть асимптотичний час виконання програми у явному вигляді, 
якщо для нього відоме рекурентне співвідношення

​a) T(n) = {O(1), n = 0;
           T(n - 1) + O(1), n >= 1}

T = O(n)

​d) T(n) = {O(1), n <= a, a > 1; 
          aT(n - a) + O(1), n > a}

 O(a^(n/a))

​g) T(n) = {O(1), n = 1;
           aT([n/a]) + O(1), n >= 2, a >= 2}

n = a^m
T = aT(a^(m-1)) + O(1) = a^2 * T(a^(m-2)) + a + O(1) =...=
= a^m * O(1) + (a^(m-1) + ... + a + O(1))
T = 0(a^m) = O(n)
      
​h) T(n) = {O(1), n = 1; 
           aT([n/a]) + O(n), n >= 2, a >= 2}

n = a^m

T(n) = a * T(n/a) + n =
     = a * (a * T(n/a^2) + (n/a)) + n
     = a^2 * T(n/a^2) + 2n
     = a^3 * T(n/a^3) + 3n
     = a^m * T(n/a^m) + mn
T = O(n+mn) = O(n log (n))
